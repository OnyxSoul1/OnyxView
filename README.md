# OnyxView - HDMI Capture Card Viewer

**DESIGN ENGINE ARCHITECTURE BY ONYXSOUL**

OnyxView is a production-ready, ultra-premium Progressive Web App (PWA) system for low-latency HDMI capture card viewing. Built with a stunning cyber-synthwave aesthetic, it transforms your gaming experience with real-time video controls, retro CRT effects, and seamless offline functionality.

## Key Features
- 🎮 **1080p@60fps streaming** with minimal latency
- 🌐 **Offline-first** architecture (works without internet)
- 🎨 **Cyber-synthwave UI** with animated matrix grid
- 📺 **CRT scanline overlay** for retro gaming feel
- 🎛️ **Real-time filters** (brightness, contrast, saturation)
- 📱 **PWA ready** - install as standalone app
- 🔌 **Hot-swap support** - plug/unplug devices live
- ⚡ **Zero audio processing** for clean game capture

## Perfect For
- Console gaming (PS4 Pro, PS5, Xbox Series X)
- Capture card testing and monitoring
- Retro gaming with authentic CRT aesthetics
- Streaming setup and preview
